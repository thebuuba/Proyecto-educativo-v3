# Afiche

Adaptaciones evaluativas de Aula Base, no instrumentos oficiales del MINERD. La evidencia JSON conserva todos los instrumentos y variantes del servicio normal.

## rubrica · 20 puntos

- **Mensaje del afiche (5 pts)**: Comunica acciones o ideas pertinentes sobre la convivencia escolar mediante un mensaje breve, claro y persuasivo.
  - Destacado: Comunica acciones o ideas pertinentes sobre la convivencia escolar mediante un mensaje breve, claro y persuasivo.
  - Logrado: El mensaje comunica la idea central; una expresión necesita precisión.
  - En proceso: El mensaje es reconocible, pero contiene ideas ambiguas o ajenas al propósito.
  - Inicial: No comunica un mensaje reconocible del afiche.
- **Adecuación al público destinatario (4 pts)**: Adapta el vocabulario, el tono y el llamado a la acción a la comunidad o público indicado.
  - Destacado: Adapta el vocabulario, el tono y el llamado a la acción a la comunidad o público indicado.
  - Logrado: El vocabulario y la acción corresponden al público; una expresión requiere ajuste.
  - En proceso: El público se reconoce, pero parte del lenguaje o la acción no se adecua a él.
  - Inicial: No permite reconocer a quién se dirige el afiche.
- **Argumentos y recursos persuasivos (4 pts)**: Usa recomendaciones, argumentos o expresiones persuasivas pertinentes, sin inventar datos.
  - Destacado: Usa recomendaciones, argumentos o expresiones persuasivas pertinentes, sin inventar datos.
  - Logrado: Los argumentos o expresiones apoyan el mensaje; una relación necesita precisión.
  - En proceso: Usa expresiones para convencer, pero algunas no sustentan el mensaje.
  - Inicial: No aporta argumentos ni recursos persuasivos reconocibles.
- **Relación entre texto y elementos visuales (4 pts)**: Relaciona el texto con la alternativa visual elegida: imagen o símbolo.
  - Destacado: Relaciona el texto con la alternativa visual elegida: imagen o símbolo.
  - Logrado: El recurso visual se vincula con el texto; una relación necesita mayor claridad.
  - En proceso: Texto y recurso visual se relacionan parcialmente y compiten por comunicar la idea.
  - Inicial: No presenta el recurso visual solicitado ni una relación reconocible con el texto.
- **Organización, legibilidad y corrección (3 pts)**: Presenta la información con jerarquía visual, lectura clara, ortografía cuidada y contenido pertinente.
  - Destacado: Presenta la información con jerarquía visual, lectura clara, ortografía cuidada y contenido pertinente.
  - Logrado: El texto se lee y se organiza con claridad; un detalle de escritura necesita ajuste.
  - En proceso: La organización o varios errores dificultan comprender partes importantes del afiche.
  - Inicial: No presenta un texto legible y organizado para comunicar el mensaje.
